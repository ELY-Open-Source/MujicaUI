# 020 Kbd 快捷键

## 用途

把单键或组合键显示为键帽。按平台显示：macOS 用 ⌘ ⇧ ⌥ ⌃ 等符号且不加连接符；其他平台显示 Ctrl、Shift、Alt，键之间用“+”连接。只做展示，不注册快捷键。

## 最小示例

```go
view := func(c *ui.Context) {
	core.Use(c, core.Settings{})
	ui.Row(c).Gap(6).Children(func() {
		display.Text(c, "Command palette", display.TextOptions{})
		display.Kbd(c, "Mod", "Shift", "P")
	})
}
```

## 参数

`func Kbd(c *ui.Context, keys ...string) ui.Element`

至少要传一个键，键名不能为空，否则 panic。键名不区分大小写：

| 键名 | macOS | 其他平台 |
| --- | --- | --- |
| `Mod` | ⌘（Command） | Ctrl |
| `Ctrl` | ⌃ | Ctrl |
| `Alt` | ⌥（Option） | Alt |
| `Shift` | ⇧ | Shift |
| `Enter` | ↩ | Enter |
| `Esc` | esc | Esc |
| `Tab` | ⇥ | Tab |
| `Backspace` | ⌫ | Backspace |
| `Delete` | ⌦ | Delete |
| `Up` `Down` `Left` `Right` | ↑ ↓ ← → | ↑ ↓ ← → |

其他键名按原样显示；单个字符转为大写。

## 状态

纯展示。键帽随系统文本缩放放大，使用等宽字体、`Surface` 底色、`ControlBorder` 边框，底边 2 DIP。

## 事件

无。

## 键盘操作

不获取焦点，也不注册任何快捷键。辅助技术读出完整的组合键文字，例如“Command+Shift+P”或“Ctrl+Shift+P”。

## 限制

- 平台在编译时由 `runtime.GOOS` 决定。Gallery 的网页镜像显示的是运行 Go 进程那台机器的平台。
- `Mod` 与 MyGo 的 `ui.Cmd` 一致：macOS 上是 Command，其他平台是 Control。
